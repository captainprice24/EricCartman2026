## v16-01-c

An approved environment needs an independent security assessment made after its latest software migration. An older assessment remains usable only if the migration changed neither access control nor export functions; a developer's internal assurance is insufficient.

The office validly released a dataset linking an openly licensed source to a freely viewable restricted register. It kept stable person-level keys, and a recent migration changed its environment's export function. The register owner had earlier permitted analysis alone. No other route existed, and release notices need not reproduce permissions or security reports.

Which of the following statements is supported by the passage?

B. The analysis permission covered distribution because anyone could already view the register.
C. The independent assessor had helped to design the environment's original export function.
D. The register owner charged a distribution fee higher than the cost of the security assessment.
